# 메모리 엔더 (Memory Ender)

기억을 지우는 장의사가 장례를 거부한 망자를 쫓는 짧은 웹 게임입니다. 플레이 시간은 약 5분입니다.

- 플레이: https://sei-ban.github.io/memory-ender/
- 구성: 추리 → 추격 → 장례

## 조작
- 추리: WASD / 방향키로 이동, 마우스를 누르고 있으면 조등 전파로 탐색
- 추격: 스페이스 / W / ↑ 점프, 마우스 클릭으로 포착·연타·발사, 마지막에는 망자를 누르고 있기
- 장례: 빛나는 갑옷을 붙잡고 끌어당겨 뜯어내기, 마지막에는 망자를 누르고 있기
- M: 소리 켜기 / 끄기
- 타이틀의 챕터 선택(1. 추리 / 2. 추격 / 3. 장례)으로 원하는 구간부터 바로 볼 수 있습니다. 플레이 중 Esc를 누르면 타이틀로 돌아갑니다.

## 만든 사람과 역할
- 기획·설계·튜닝 결정: 김준현
- 코드 구현: Claude(AI). 기획서의 규칙과 수치를 바탕으로 AI가 코드를 작성하고, 직접 플레이하며 수치와 조작을 고쳤습니다.
- 그래픽: 외부 이미지 없이 도형으로 그렸습니다.
- 사운드: 외부 음원 없이 브라우저(Web Audio)에서 직접 합성했습니다.
